    About

    I like the parts of software most people never see: the API contracts, the auth rules and the tests that keep a system honest.

    I'm in my final year of the IIE Bachelor of Computer and Information Sciences in Application Development at Emeris. I've built secure REST APIs with JWT and role-based access control, worked with SQL Server, MongoDB and Firebase, deployed to Microsoft Azure, and collaborated through Git with automated testing and CI.

    This year I led a six-member Work-Integrated Learning team building REGGY, a student registration platform for an institutional client, and took primary ownership of the API that connects its Flutter app and ASP.NET Core staff portal.
